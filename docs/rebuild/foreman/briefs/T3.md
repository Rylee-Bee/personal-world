# T3: whole-world strip and Home
Depends on T2 (Row, Meter) being applied. Read `briefs/COMMON.md`, `ui/src/fd/{api,home-model,prefs}.ts(x)`, `ui/src/fd/Row.tsx`, `ui/src/test/fd-home.test.tsx`.

Create `ui/src/fd/Strip.tsx`: `Strip({ rows, onSelect })`, `rows: Row[]` (type from home-model; alias the import to avoid clashing with the Row component), `onSelect(cardId: string): void`. A `<div role="group" aria-label="Whole world">` with one `<button>` per source: icon (decorative), name, state shape + word. Accessible name exactly `{title}: {State word}. Show details`. At least 56px tall; wraps; a 4-column grid below 600px.

Create `ui/src/fd/Home.tsx`: `Home({ timeZone })`. Uses `useHomeData()` and `usePrefs()`. Structure, in this order inside one wrapper: `<h1>Home</h1>`, a paragraph with the briefing (`briefing()` of `buildSections()`; for Minimal words show only the facts line, same text), the Strip (all visible items, board order), a quiet `<button>Edit Home</button>` (does nothing yet), then five `<section>`s each with an `<h2>`: Needs you, Needs a look, Pick up, Your life, Quietly working, using `SECTION_TITLE`. Each section with rows renders a `<ul>` of `Row`s. An empty section still shows its heading plus one short line ("Nothing for you right now.", "Nothing needs a look.", "Nothing to pick up.", "Nothing here yet.", "Nothing running."). Pick up has no data source yet: always its empty line.
Drill-in: state `openId: string | null`; clicking a row's button or a strip button sets/clears it; only one is open; the strip click opens the matching row's drill-in (it is rendered by Row with `expanded`). `buildSections` must be computed once per data load, never recomputed because of focus or openId changes (use `useMemo` on the data).
Cards that failed (`failed` ids from `useHomeData`) become a synthetic envelope: `source_state: "unknown"`, `freshness: "stale"`, empty values, `meter: null`, last_good_at null, meaning from the board title, evidence with the request id `board.<card>` and `error_class: "connection"`. They show "—" and Unknown, never 0. Loading shows a single polite line "Loading Home". A board load error shows "Home could not load. Try again." with a "Try again" button.
Quiet group in Calm density: rows in Quietly working fold into one line ("N quiet: names, comma separated") with a button to expand them.
Styles in `ui/src/fd/fd.css` under `/* home */` (shared: append).

Acceptance: `cd ui && npx vitest run --project unit src/test/fd-home.test.tsx`
