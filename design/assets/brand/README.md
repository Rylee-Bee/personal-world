# Brand

- `app-icon.png`: the Worlds app icon, 1024² and navy to the edges (Sol on a
  navy tile with gold stars; `docs/ART-REQUESTS.md` §13). The browser tab,
  home-screen and install icons in `ui/public/` are exported from it.
- `app-icon-maskable.png`: the same art at 80% on the tile's own navy, so a
  circle crop (Android) keeps the whole ring. `ui/public/icon-maskable-512.png`
  comes from it.

The owner's original export had a white margin around a rounded tile; these
masters crop past it, because platforms apply their own rounded shape.
